# Credits

## Made for this mod

- All Java code, the GeckoLib/vanilla-style character model (`HelperGaiaModel`), the `HelperBody` procedural
  animation engine (gait, weapon stances, kinetic-chain attacks) and its sister `HelperMotion` layer, the
  `design/entitykit` skin/motion authoring toolkit, and the quest/voice/brain integration code were written for
  Blighted Helper.
- **Emily's base skin** (`emily_gaia.png` and the four companion skins painted from it) is hand-painted pixel art,
  generated procedurally by `design/helper_art/skin/make_emily_gaia.py`. An earlier version of that script (used
  through 2026-10-21) pasted small cropped regions of Grimoire of Gaia 4's `Succubus`/`Valkyrie` textures for the
  head, hair and wings; it was rewritten on 2026-10-22, before this repository's first publication, to paint those
  regions from scratch instead. Nothing in this repository is copied from Grimoire of Gaia's asset files.
- **Emily's 2D "standee" art** (`assets/blighted_helper/textures/entity/emily_standee/`) is cut and layered from
  `design/helper_art/GROK_SHEET.jpg`, a reference sheet the project's author generated themselves with Grok (xAI).
- **Emily's high-resolution 3D model** (`design/helper_art/emily3d/final/`) is a hand-built, hand-rigged model
  (120k triangles, 160 bones, 4096px painted textures), built procedurally in Blender from original geometry --
  not generated by an image-to-3D AI tool. It is not wired into the mod yet; it ships here as source art for future
  use. See `design/helper_art/emily3d/final/README.md` for the full breakdown.
- Voice is synthesized locally by [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) (Apache License 2.0), run by
  the small server in `design/tools/voice-server/`. The model weights are downloaded by that server at first run,
  not bundled in this repository.
- The in-game "mind" (chat, tool use) can run against a local [llama.cpp](https://github.com/ggml-org/llama.cpp)
  (MIT License) server with a GGUF model of your choice, or against an OpenAI-compatible API such as Groq or
  Google's Gemini, using your own API key.

## Modelling technique studied, nothing copied

`design/helper_art/MODEL_STUDY.md` records a read-only study of how well-regarded GeckoLib models (and Yes Steve
Model's own bundled example models) build hair, cloth and eye rigs, done to learn the *technique* -- flat alpha-cut
cards, chained rotated segments, a proper eye rig. No third-party geometry, texture or animation data was copied
into this mod; only the modelling approach was learned from and reapplied with original data.

## Compile-time integrations (not included in this repository)

Blighted Helper optionally compiles against and reacts to the following mods, so it can offer compatible combat
animations, equipment slots, and spell-casting hooks when they are present. None of their code, assets or jars are
redistributed here -- `build.gradle` compiles against copies of these jars that you provide locally (see
*Building*, below), and the mod simply does nothing special for a given integration if that mod isn't installed.

| Mod | Used for | License |
|---|---|---|
| [GeckoLib](https://github.com/bernie-g/geckolib) | Base animation engine for Emily's model | MIT |
| [Curios API](https://github.com/CuriosAPI/curios) | Extra equipment slots | LGPL-3.0-or-later |
| [Better Combat](https://www.curseforge.com/minecraft/mc-mods/better-combat-fabric) | Combat-state detection for stances/attacks | All Rights Reserved -- integration only, no code or assets included |
| [Relics](https://www.curseforge.com/minecraft/mc-mods/relics) | Relic-based stat scaling hooks | All Rights Reserved -- integration only, no code or assets included |
| [Iron's Spells 'n Spellbooks](https://www.curseforge.com/minecraft/mc-mods/irons-spells-n-spellbooks) | Spell-casting animation hooks | All Rights Reserved -- integration only, no code or assets included |
| [Hazen N Stuff](https://www.curseforge.com/minecraft/mc-mods/hazennstuff) | Spell-school attribute hooks | Polyform Shield License 1.0.0 |
| [Champions](https://www.curseforge.com/minecraft/mc-mods/champions) | Boss/affix compatibility | LGPL-3.0 |
| [Architectury API](https://github.com/architectury/architectury-api) | Cross-loader utilities pulled in by the above | LGPL-3.0 |

## Excluded from this repository on purpose

A design folder of about 2.6 GB of in-progress art (ComfyUI renders, AI image-to-3D experiments that were tried
and abandoned, reference photos, work-in-progress screenshots, and planning documents for unrelated parts of the
Blighted Dreams modpack) was not carried over -- it documents the *process*, not the shipped mod, and some of it
is lower-resolution scratch work superseded by the files that are here.
