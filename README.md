# Blighted Helper

A NeoForge 1.21.1 mod that adds **Emily**, a companion for the *Blighted Dreams* modpack: a combat-capable ally
with five selectable forms (Dragoness, Infernal Fiend, Seraph, Astral Mystic, Harlequin), a local text-to-speech
voice, an optional LLM "mind" for free-form chat, and a hand-built procedural animation engine driving her gait,
weapon stances and attacks.

This repository has the mod's source, the toolkit that generates her skins and motion data, and her original
design art. See [CREDITS.md](CREDITS.md) for what every piece is built from.

## Features

- **Five forms**, chosen from an in-game starter screen, each with its own stats, spell school and 3D look.
- **Procedural body animation** (`HelperBody.java`): two-bone leg IK with planted feet, a phase-warped gait with
  pelvis bob/sway/twist and banking into turns, per-weapon fighting stances and relaxed carries, and attacks
  written as a kinetic chain (hips lead, chest follows, then the arm) with anticipation, a stepping lunge and a
  follow-through. The same restricted-Java region of the code is transpiled to JavaScript (see
  `design/entitykit/anim`) so the exact same math drives an in-browser model-and-animation studio used to author
  and check the look before it ships.
- **Local voice**, synthesized by [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) through a small Python server
  (`design/tools/voice-server`) that runs on your own machine.
- **An optional LLM mind**: free-form chat either through a local `llama.cpp` server with a GGUF model of your
  choice, or an OpenAI-compatible API (Groq, Google Gemini) using your own key.
- **Combat integration** with GeckoLib, Curios, Better Combat, Relics, Iron's Spells 'n Spellbooks, Hazen N Stuff
  and Champions when they're installed (see CREDITS.md); the mod runs fine without any of them.

## Building

Requires JDK 21 and the NeoForge Gradle toolchain (handled by the wrapper).

```
cd blighted_helper
./gradlew build
```

The build jar appears in `blighted_helper/build/libs/`. Some integrations (GeckoLib, Curios, Better Combat,
Relics, Architectury, Iron's Spells 'n Spellbooks, Hazen N Stuff, Champions) are compiled against as
`compileOnly fileTree(dir: '../mods', ...)` in `build.gradle` -- drop the jars of whichever ones you want built
against into a `mods/` folder next to `blighted_helper/` (a sibling directory, not inside it); the mod builds and
runs fine with none of them present.

## Regenerating the art

Emily's skins and extra variant parts (`design/entitykit/skin/`) and her procedural motion data
(`design/entitykit/anim/`) are generated by small Node scripts, not hand-edited PNGs/JSON:

```
cd design/entitykit
node skin/build_hd.js --install    # paints the skins + extra parts, writes them into the mod's resources
node anim/build_motion.js --install  # compiles the authored motion clips into motion.json
```

`design/entitykit/studio/serve.js` serves a live, orbitable preview (`http://localhost:8765`) of every form and
every animation, running the actual transpiled `HelperBody`/`HelperMotion` code, so you can check a change before
installing it.

`design/helper_art/skin/make_emily_gaia.py` (needs Pillow and numpy) paints Emily's base texture from scratch and
renders a 4-angle proportions check.
