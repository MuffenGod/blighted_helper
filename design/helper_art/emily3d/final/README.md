# Emily 3D model (2026-10-17)

Clean, rigged, hand-built 3D character of the horned half-dragon from the low-poly sheet (Front / Side / Back / Idle).
Built procedurally (numpy + Blender 5.2), not generated by an image-to-3D AI, because those came out lumpy and clay-like.

## Files

| file | what |
|---|---|
| `emily.glb` | skinned model, 4096 px textures, 160 bones, `Idle` loop (glTF Y-up, faces +Z) |
| `emily_2k.glb` | same with 2048 px textures (9.5 MB) |
| `emily.blend`, `emily_2k.blend` | Blender 5.2 scene with rig, materials and packed textures (Z-up, faces -Y, her left = +X) |
| `textures/` | `emily_B_*` (body sheet: face, skin, dress, shoes) and `emily_X_*` (extras sheet: hair, horns, wings, tail), each `_albedo` / `_orm` (R = baked AO, G = roughness, B = metal) / `_normal` (OpenGL, tangent space). `textures_2k/` = half size |
| `emily_turnaround.png`, `emily_closeups.png`, `emily_vs_reference.png`, `emily_pose_test.png`, `emily_turntable.gif`, `previews/` | renders (Cycles) |

## Numbers

- 120,764 triangles (hero version), 5 skinned meshes (`Emily_Body`, `_Outfit`, `_Hair`, `_Wings`, `_Dragon`), 2 materials, 6 texture maps at 4096 x 4096.
- Height 1.70 m to the top of the hair, 1.87 m with the horns, wingspan about 1.6 m.
- Every part is a closed manifold shell (checked by `check_mesh.py`), no flipped or degenerate faces, no unintended UV overlap.
- 160 bones: spine/neck/head, arms with 5 three-bone fingers per hand, legs with toes, 8 bones per wing (arm, forearm, three two-bone fingers) plus claw, 9-bone tail, 16 skirt bones (8 chains x 2), 3-bone chains for every back and front hair lock, ears.
- Skin weights are computed from the geometry (chain blending along limbs, capsule falloff on the wings, per-finger weights); wings, tail, skirt and hair are meant to be driven by animation or physics.

## What is on the model (checked against the sheet)

Pointed elf ears, side-parted long blonde hair with a V-shaped back and face-framing curtains, emerald green eyes with a sly sideways glance and a smirk showing teeth, black curved horns with cream inlay lines, black dragon wings with bone fingers and mauve membranes, scaled tail with dorsal plates curling on the floor, mock-neck lace collar with a green gem pendant, sweetheart bodice with gold leaf ornament, puff shoulder sleeves, fingerless black arm warmers with gold trim and black nails, floor-length gown with a high front-left slit, gold piping and filigree vines and hem ornament, black ankle-strap heels.

## Rebuilding (all sources are in `design/helper_art/emily3d/`)

```
python -I build_all.py            # geometry -> out/model.npz + out/rig_spec.json  (numpy/scipy; ComfyUI's python works)
python -I paint_all.py            # UV atlas + all painters -> tex/ (use arguments to repaint only matching groups)
blender -b -P bl_bake_ao.py -- out/model_tex.npz tex 48 0.22   # ambient occlusion (about 9 minutes), then:
python -I paint_all.py --compose  # albedo x AO, normal maps
blender -b -P bl_rig.py -- out/model_tex.npz out/rig_spec.json tex final      # rig, .blend, .glb
blender -b -P bl_tex.py -- out/model_tex.npz tex prev/out front,three,face 1200 CYCLES 128   # renders
```

Note: the AO bake depends on the UV layout, so redo it after any geometry change.

## Known limits

- Face is painted (no blend shapes, no separate eyeballs), so expressions need texture swaps or UV-offset tricks.
- Hand fingers are rigged but the hand is stylised (mitten-like palm).
- 120k triangles is a hero budget; a game LOD would need a retopology or lower-resolution rebuild (the builders take segment and ring counts).
- Hair and skirt are separate overlapping shells (no physics baked in).
